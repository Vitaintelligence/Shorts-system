# Creative

Turn an analysis into five concepts, then wait for a person to pick one.

**Input:** `analysis.md` with timecoded observations.

**Output:** `concept.json` and `concepts.md` from [the five-concept template](../../docs/CONCEPTS_TEMPLATE.md).

The sample writes `status: "blocked"` and `conceptCount: 0`. Generating copy here would invent an angle for an app the pipeline has not seen.

The role spec is [the creative director](../../agents/creative-director.md).
