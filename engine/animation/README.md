# Animation

Shots that are designed rather than captured.

**Input:** an edit that needs a shot the recording does not contain, plus the cited fact that shot is allowed to show.

**Output:** `animation.json` and, later, a Remotion composition. three.js inside Remotion is a fit when a shot needs a camera in a built scene. Build original scenes. Do not import characters, worlds, or footage from the reference project named in [NOTICE](../../NOTICE).

The sample writes `mode: "none"`. A title card is motion graphics, not an animated scene, and the sample must not draw a fake phone UI.

Product facts inside an animated shot still need an analysis timecode. The role spec is [the motion designer](../../agents/motion-designer.md).
