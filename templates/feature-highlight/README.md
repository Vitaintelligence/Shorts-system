# Feature highlight

One behavior, named the way the product names it on screen, held long enough to see.

## Inputs

- One analysis block for that behavior
- A recording span where the behavior starts and finishes
- Chosen concept

## Outputs

- A script whose factual sentences all cite that block
- An EDL that does not cut away to a second, uncited feature
- Master and platform exports

## Fill in

- On-screen label:
- Paraphrase, if you must use one (and the label it stands in for):
- Timecode in / out:
- First-second hook:
- Words you will not add to "strengthen" it:
- Estimated duration:

## Refuse

A montage of other features. A before/after the recording does not contain. A metric ("faster", "more") without a visible number or a user-supplied measurement marked as supplied.
