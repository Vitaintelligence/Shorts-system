# Animated story

Use when a cited fact is clearer drawn than captured. The drawing illustrates the analysis. It does not replace it.

## Inputs

- The fact, in one sentence, with an analysis timecode
- A list of pictures that fact allows (objects, not imagined UI)
- A decision that screen video cannot carry this beat

## Outputs

- A shot list of original animation
- A Remotion composition at 1080×1920, 30 fps, when the shot is produced
- Master and platform exports mixed with real captures where the concept uses both

## Refuse

A fake product UI. A character who "uses the app" in a way the recording does not. Any asset copied from the reference animated short that inspired this system's pipeline shape.

This template has no sample scene in the repo. `npm run produce:sample` renders a title card, not an animated story.
