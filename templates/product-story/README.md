# Product story

Tell one real session in order. The subject is the session. A person appears only if they agreed, and only saying what they agreed to say.

## Inputs

- A continuous recording, or ordered spans from one session
- Analysis of those spans
- Written consent note if any real person's voice or face is used (store the note outside git if it contains personal data; record that it exists)

## Outputs

- A narrative script that does not rearrange events into a cause the recording does not show
- EDL in session order
- Master and platform exports

## Fill in

- Session id or date:
- Beat list with timecodes (start, turn, result):
- Who speaks, and whether they are a narrator or the recorded person:
- Lines the story must not include:
- Estimated duration:

## Refuse

A fictional user. A composite of several sessions presented as one. Invented dialogue in quotation marks.
