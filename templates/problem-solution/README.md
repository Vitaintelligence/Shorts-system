# Problem / solution

Show a situation and the response that is actually in the recording.

## Inputs

- Analysis timecodes for the response
- Either a visible problem in the recording, or a sentence the user supplied, labeled `supplied, not observed`
- Chosen concept

## Outputs

- Script with the problem line and the response line kept distinct
- EDL that shows the response, not a stand-in
- Master and platform exports
