# Templates

Formats for a short after a concept is chosen. Each folder is a brief, not a rendered example.

Pick one:

| Template | Use when |
| --- | --- |
| [app-demo](app-demo/README.md) | The recording can carry the whole short |
| [feature-highlight](feature-highlight/README.md) | One demonstrated behavior is the entire point |
| [problem-solution](problem-solution/README.md) | The recording shows a situation and the app's response |
| [product-story](product-story/README.md) | One real session is worth telling in order |
| [ugc-style](ugc-style/README.md) | A real person will deliver the lines to camera or as VO |
| [cinematic](cinematic/README.md) | Grade, pace, and type do the work on real captures |
| [animated-story](animated-story/README.md) | A cited fact is clearer drawn than screen-captured |

Rules for every format:

- The picture of the product is the recording, or original type and animation of a fact the recording supports.
- Do not mock a screen, generate a fake device UI, or borrow a claim from the app store listing unless that listing text is itself cited and the user asked for it.
- On-screen text matches the script. Captions are burned in. An SRT is written beside the export.
- Master spec is in [docs/PIPELINE.md](../docs/PIPELINE.md): 9:16, 1080×1920, 30 fps, MP4, H.264, AAC.
- LIVI is the first app this system will serve. These templates stay empty of LIVI features until an analysis file cites them.
